# 隐私与凭据

仓库不包含维护者的 API Key、Token、账号配置、聊天记录、角色资料或未授权的私人媒体。`docs/images/` 中的图片仅用于 README 展示，其中的角色形象已获准公开；角色原图与运行时数据没有随仓库发布。

运行时填写的服务配置保存在本机的 `app/data/`。密钥字段使用本机生成的随机密钥加密；随机密钥位于同一数据目录并被 Git 忽略。这可以避免凭据以明文出现在配置文件中，但不替代操作系统账号隔离和磁盘安全。

角色资料与聊天记录主要保存在浏览器本地存储中，用户上传的角色图片保存在本机数据目录中。录音会发送给配置的语音识别服务；角色设定、记忆、近期聊天与识别文字会发送给对话服务；回复文字会发送给语音合成服务。

提交 issue、日志或截图前，请移除服务凭据、账号标识、私人对话和角色图片。
